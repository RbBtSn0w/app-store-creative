# In-App Events 实施与验收计划

E1–E4 的本地 CLI 已实现，E5 真实活动待试点。范围与字段定义见[技术设计](../prd/in-app-events-design.md)。技术验收与真实活动运营分别记录；只有已取得 Apple 回读或目标 App 运行证据的项目才记录为真实验证。

## 可独立合入的工作包

| 顺序 | 依赖 | 工程交付 | 合入或试点门槛 |
|---|---|---|---|
| E1 契约与候选决策 | 当前 CLI 启动器 | 新增 brief/schema、入口、事件目录与项目身份校验；提供普通修复和限时挑战两份合成 brief；编写 Agent 收集事实、标注缺口和输出决定的指引 | 安装后的启动器在非项目目录可输出 propose/defer/skip；旧项目无需迁移；T01–T04 通过 |
| E2 排期、素材与深链 | E1 | 实现纯函数时间扫描、库存导入、图片解码、路由证据导入及 findings，输出各地区的冲突时间和对象；提供 App 侧 XCUITest 对接示例 | T05–T14 通过；离线验证能区分失败及证据缺失，原始文件不变 |
| E3 冻结交接与状态观察 | E1、E2 | 增加 handoff、observe、Publisher 操作与恢复说明、事件锁和收据绑定；支持按地区定制或付费活动的界面步骤 | T15–T21 通过；模拟崩溃后续跑只补缺项；一次双语言静态活动可离线交接 |
| E4 结果判读 | E1 确定策略，E3 提供活动绑定 | 实现两类聚合快照导入、原因码、门槛判读和结果回放；同步安装包说明与示例 | T22–T25 通过；有数据、数据不足、口径错误三种输出可从原始 fixture 复算 |
| E5 真实试点 | E1–E4，业务方有可参与的活动及目标 build | 先观察真实 CLI 响应并脱敏对照，再跑两语言资产、设备深链、草稿回读和常规发布交接；观察活动直到首个可解释的分析结果 | T26 分段签收。记录 App、版本、地区、素材摘要、远端 ID、状态来源、复办或调整决定；缺少真实活动时记录待试点 |

E1–E3 是可演示的最小交付，E4 完成产品反馈闭环。试点优先选择已有内容、免费、统一时间的真实活动；无需为验证工具而在产品中开发虚构玩法。首个 PR 开始时复查共享入口和打包脚本的并行变更，按实际目标分支接入。每包独立提交测试与集成点，只在相应能力就绪后更新用户入口。发生回归可撤回该入口并保留版本化记录，远端已创建的活动按原 eventId 继续管理。

## 测试设计

标准库 unittest.TestCase + TemporaryDirectory，固定时钟并注入 ASC 读取与进程调用；网络调用在 CI 中由 fixture 替代。合成 App 使用固定 bundle ID、可区分的首页/活动页 accessibilityIdentifier、可控时间和开关。远端模拟器记录每次实际写入并支持「已写入但丢响应」；断言最终资源集合和调用次数。受控试点复核 fixture 与已安装 CLI 的 JSON 路径、枚举、分页、媒体交付状态与权限。

| ID | 输入或故障注入 | 期望结果 |
|---|---|---|
| T01 | 同一 agent 输入分别为普通修复、有依据的限时挑战、排期存在但内容未交付 | skip、propose、defer；每条承诺可回查，推测的奖励不会进入交接 |
| T02 | 父/子位置传 --repo，从外部 cwd 启动，旧配置无活动 | 两种路径解析结果一致，既有命令和项目继续运行 |
| T03 | 未知契约版本、危险 eventKey、越界 symlink、被改写的证据 | 标出具体字段或摘要冲突，项目外没有写入 |
| T04 | 主语言缺失、两个 locale 重复、30/50/120 与各超一字符、重名参考、组合字符 | 普通边界可通过，超限/重名被定位，Unicode 边界保留原文供 ASC 校验 |
| T05 | 15 分钟、31 天、14 天预热，各偏离允许范围一秒 | 边界通过，超界出现对应原因码 |
| T06 | 跨午夜、夏令时重复小时、区域起始跨度 48 小时及超一秒 | 显式偏移正常换算，模糊输入需消歧，超界指出地区 |
| T07 | 49/50 个草稿再建；14/15 个获批再批准；已绑定事件更新 | 达到限额允许，超限阻塞相应动作，同一事件不重复计数 |
| T08 | 10 个展示占位加一条仅预热相交；相邻边界；11 条草稿活动重叠 | 区分展示冲突与活动冲突，输出名单和时段，首尾相接可通过 |
| T09 | 同一事件跨地区、库存重复页/缺页、旧快照、不可售地区 | 合并唯一 ID；缺页/旧数据需刷新，不可售地区报告配置错误 |
| T10 | 横竖图最小/最大尺寸、方向反转、长边偏一像素、超限、伪装 PNG 或截断 | 有效边界通过，坏文件精确定位 locale × slot；大小边界可注入文件长度测试 |
| T11 | 中文详情图缺失、明确共享同图、替换素材但保持同名、输入视频 | 分别报告缺图、验证共享引用、摘要失效、暂不支持的视频处理 |
| T12 | 冷/热启动、首次安装经过 onboarding、登录后返回 | 到达指定 eventKey 和页面，可执行活动动作；仅显示首页失败 |
| T13 | 预热、结束、不同地区、旧 build、路由测试来自另一 build | 显示对应预告/已结束/地区体验；错误 build 的证据不能放行 |
| T14 | 付费、地区分时、受限 CLI 及统一免费配置 | 前两类生成准确的人工步骤；统一免费可用 CLI；任何条件均不可静默改写 |
| T15 | 同一输入重复 handoff，随后改变地区、图像或授权摘要 | 重放产生同一业务摘要；变更要求新交接，原授权不能覆盖 |
| T16 | 远端已创建但响应超时，短暂不可见，或同名但字段不匹配 | 唯一匹配后复用；仍不确定时阻塞，不会二次创建 |
| T17 | 第一个 locale 上传成功后中断；资产 processing、failed 或内容冲突 | 恢复时保留成功项；处理中的回读，失败项按证据修复；冲突列出远端 ID |
| T18 | 首版待审；已有版本；半完成 submission；草稿内有无关 item | 正确选择首版或独立提交，复用正确草稿；无关 item 不被一起提交 |
| T19 | 待审核、拒绝、待发布、已发布、已结束和未识别状态 | 时间流逝不会自行产生已发布事实；拒绝留原因，未知状态需核查 |
| T20 | 403、429、服务异常、读取中断、写后回读发现第三方修改 | 有界重试读取，权限错误可诊断，存在远端冲突时保留当时证据 |
| T21 | 两进程竞争同一事件指针，或 intent 写入后进程退出 | 无半写 JSON；失败方重读并核实远端，已完成动作不重复执行 |
| T22 | Apple 报表缺失但有 App 参与；可见且确为零；隐私抑制 | 区分未知和零，保留产品读数与不同来源的覆盖情况 |
| T23 | 策略下限 40，分别为 39/39、20/40、19/40（完成/开始） | 样本不足、达到门槛、低于门槛；零分母无比率 |
| T24 | 不同时间窗或 event ID、分子大于分母、布尔计数、重复或修订报告 | 错误映射/口径被拒绝；相同报告去重，修订保留来源与前一摘要 |
| T25 | 安装包在空项目离线重放从 brief 到判读；随后取消活动数据来源 | CLI 所有新入口可用，相同输入产生相同决定；删去数据后输出证据不足 |
| T26 | 一场已确认存在的真实活动，真机与 ASC 逐步验证 | 分别留存路由、草稿、素材处理、审核、上线与数据观测；审批延迟和分析不可见单独记载 |

## CI 与试点交付

新增 tests/test_in_app_events_*.py，测试数据仅用合成或脱敏文件。各 PR 先跑活动用例，再走现有 macos-15 四分片与汇总。离线 E2E 走实际安装包入口。App 专属设备验收放到试点 App 的已有 UI 测试目标，避免每次插件单测依赖业务 App、登录态或 ASC 凭据。

```sh
python3 -m unittest discover -s tests -p 'test_in_app_events_*.py'
python3 .github/run_sharded_tests.py --shard 1 --total 4
python3 -m unittest discover -s tests -p 'test_*.py'
```

E5 需要 App 负责人给出真实活动、目标 build、上线窗口与可用的远端权限。若暂缺其中一项，交付 E1–E4 的可重放结果及具体缺口；不把模拟链路记为真实发布。运营验收检查首次落点是否可参与、Apple 与 App 侧数据分别能回答什么、是否已记录下期决定。后续是否加入 Studio 日历，取决于试点是否出现需要同时比较多个活动档期的真实任务。

## 实施记录 · 2026-11-23

- 已接入 plan、validate、handoff、observe、assess。版本化输入契约、示例 brief、操作指引均进入插件。审批库存与草稿容量独立处理，库存不足时可准备草稿，提交动作需先刷新名额。
- macOS 活动专项包含 25 个 unittest，覆盖边界与故障回放。安装包解压后验证候选选择、双语言图、落点记录、交接、观察及结果判读。恢复测试向本地 Publisher 决策函数重放部分上传、超时和多项审核草稿的观察。真实网络退避、权限、媒体处理最终状态及设备运行证据由 E5 验收。
- [使用指引与输入契约](../../plugins/app-store-creative/skills/app-store-creative/references/in-app-events.md)；[专项测试](../../tests/test_in_app_events_workflow.py)。
- 全仓验证本次运行收集 1,387 个用例，34 个跳过，首轮 5 个失败、67 个错误。66 个错误均发生在本地 HTTP 服务绑定端口，未改动的 HEAD 副本也复现该权限错误。其余 6 个用例在最新工作区及可写 Swift 模块缓存下重跑全部通过。全仓仍需可绑定端口的 macOS runner 验收。

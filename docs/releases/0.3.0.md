# 0.3.0 待发布说明

状态：分支准备中，尚未发布。完整交付状态以 [ADR-002 实施状态](../adr/ADR-002-implementation-status.md) 为准。

## 统一产物管理

截图、预览视频、封面和证据采用同一生命周期内核。每个批次保存配置与工作流快照，每次执行使用独立尝试与租约；来源、依赖、验证、批准及交付通过不可变记录和哈希绑定。CLI、Studio 与 agent 共用配置和业务规则。

四类输出根支持项目配置及本机覆盖。正式归档固定清单和配方，Git、Git LFS 与命名外部存储分别执行独立取回验证；私有原始证据与可分享摘要分离。本机访问路径及凭据不能成为便携发布证据。

维护采用引用保护、保留计划、隔离、恢复和单独授权的永久清理。恢复先保存持久意图，进程中断可沿用原记录继续；完成状态重新核验实际字节，不根据保存日志推断成功。

## 不兼容变更

新合同是唯一执行权威。移除旧任务命令、工作流实现和旧项目／发行模板；不提供旧记录迁移、自动补写或兼容读取。已有磁盘文件不会因升级而自动删除。

新项目必须声明稳定 project_id；自定义目录不能重叠或通过别名绕过边界。变更已登记存储位置需使用显式搬迁流程。物料批准必须绑定具体候选和目标，生产成功不能替代人类批准。

## 与 ASC 的职责边界

Creative 准备物料、交接清单和证据合同；ASC 执行授权的远端操作。上传、处理、播放和封面分别核验，COMPLETE 不证明封面可用。Creative 不提交应用审核，也不从 CI 自动上传物料。
